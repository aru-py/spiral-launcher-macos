# Spiral

## Overview

This is a Keyboard Maestro macro which allows launching any site with a few letters. Simply add a tag to your Chrome bookmarks such as `Claude [cla]` and you can launch any site instantly. The advantage over other launchers such as [Alfred](https://www.alfredapp.com/) is that it is deterministic, not fuzzy, so there is no waiting for search results.

## Setup

Import the the `Spiral Launcher.kmmacros` into Keyboard Maestro and set up your bookmarks.
