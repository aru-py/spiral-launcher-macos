# Spiral

## Overview

This is a Keyboard Maestro macro which allows launching any site with a few letters. Simply add a tag to your Chrome bookmarks such as `Claude [cla]` and you can launch any site instantly.

## Setup

Import the the `Spiral Launcher.kmmacros` into Keyboard Maestro and set up your bookmarks.
